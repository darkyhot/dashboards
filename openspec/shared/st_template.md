## 6.3. Контроль качества данных

Описать словами какие проверки на таблицы или отдельные поля необходимо добавить, чтобы витрина не оказалась пустой или часть полей не была некорректна. Допускается добавить проверки сразу в прототип, с указанием в этом пункте, что проверки добавлены сразу в код.

**Обязательные проверки, после которых работа функции должна прерываться и отбрасывать статус 98:**

1. Перед финальным TRUNCATE или DELETE таргета в конце расчета, проверить на 0 кол-во полученных в результате расчета строк. Если строк в конце расчета получается 0, то в таргете должны остаться старые данные.
2. Во время расчетов после каждого получения данных из источника (внешняя таблица, таблица на ПРОМ и даже СПОД), проверить на 0 кол-во полученных строк.
3. Во время каждого деления одних данных на другие необходимо заложить проверку деления на 0 (ноль). Даже если в знаменателе не может быть 0 (ноль) согласно получаемой модели расчета данных, то и в этом случае ваш CASE должен предусматривать это случай.
4. Перед финальным TRUNCATE или DELETE таргета в конце расчета, проверить, что в загружаемых данных нет дублей - для этого определяется ключ витрины и по нему проверяется кол-во строк.
