### 2026-11-16

1. Каких клиентов проверять в триггерах «по отсутствию» (контактная политика, есть договор нет зачисления)? → Все пары ИНН + ГОСБ из `uzp_dwh_company_holding_metric`.
2. Ср чек ниже среднего: как считать? → Отрасль — `industry_name` из `uzp_data_epk_consolidation`. Средний чек ГОСБ + отрасли = сумма ФОТ / сумма получателей. Чек клиента — так же. Окно — 6 месяцев, получателей ≠ 0.
3. Если у ИНН несколько ЕПК — какую отрасль брать? → Активную, с заполненной отраслью, головную, самую новую — в этом порядке.
4. Сезонный тип: к чему считать рост? → Расчёт 07.11.2026, end_dt — октябрь 2026. Сравниваем декабрь-2025 с ноябрём-2025 и декабрь-2024 с ноябрём-2024. Рост ≥ 10% в обоих годах — триггер. `fl_uplift` — средний за 2 года прирост людей.
5. Есть договор нет зачисления: какой период? → Договор — по ИНН, без ГОСБ. ФОТ = 0 в каждом из 6 месяцев T…T-5.
6. Контактная политика: какой период? → Задачи, закрытые с 1-го числа месяца T-3 и позже. T — апрель: с 1 января, включая май. Задач нет — триггер. `task_close_date` — последняя закрытая задача за всё время с теми же фильтрами; нет — `null`.
7. ЕПП флаг: когда срабатывает? → За T у пары только выплата ЕПП. Есть выплата другого типа — триггера нет. `epp_cnt` — число получателей.
8. Заявления с зачислениями: как считать? → ЗП-коды — `is_fot_enrollment = true`. Организация любая. Зачисления — в `mis_data_payroll_d` с даты заявления. Триггер пишется и при 0 заявлений с зачислением.
9. Доля по клиенту больше 90%: условие? → `zp_fl_perc > 0.9`.
10. Еженедельные триггеры: условие? → По заявлению признаки 1/0: договор по ИНН, ЗП-зачисление человека от даты заявления до даты расчёта. Договор 0 и есть заявления без зачисления — «без договора и зачислений». Договор 1 и есть заявления без зачисления — «с договором». Договор 1 и все с зачислением — триггера нет.
