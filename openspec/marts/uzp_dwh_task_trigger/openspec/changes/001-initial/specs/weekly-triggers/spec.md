# Spec Delta

## Purpose

Правила и JSON еженедельных триггеров витрины `uzp_dwh_task_trigger` по заявлениям ВСП /
МП СБОЛ. Неделя — Пн–Вс, `end_dt` — воскресенье.

## ADDED Requirements

### Requirement: Заявления недели
Триггеры SHALL строиться по заявлениям с `report_dt` в `start_dt`…`end_dt`. Отбор заявления — как в `monthly-triggers`, «Заявление ВСП».

#### Scenario: Вне недели
- **WHEN** неделя 2026-11-09…2026-11-15, заявление 2026-11-08
- **THEN** заявление не входит в неделю

### Requirement: Признак договора
Признак договора пары SHALL быть 1, если у ИНН действующий договор (`monthly-triggers`, «Действующий договор»), иначе 0. ГОСБ договора не учитывается.

#### Scenario: Договор действует
- **WHEN** у ИНН `end_dt` > `current_date`
- **THEN** признак договора = 1

### Requirement: Признак зачисления
Признак зачисления заявления SHALL быть 1, если есть зачисление по правилу `monthly-triggers`, «Зачисление по заявлению», с `report_dt` не позже `current_date`, иначе 0.

#### Scenario: Зачисление до заявления
- **WHEN** зачисление было за день до заявления, после — нет
- **THEN** признак зачисления = 0

### Requirement: JSON недельных триггеров
Оба триггера SHALL передавать: `first_app_date` — первая дата заявления за неделю, `app_cnt` — число заявлений, `app_with_zachisl_cnt` — с зачислением, `app_no_zachisl_cnt = app_cnt − app_with_zachisl_cnt`.

#### Scenario: 3 из 10
- **WHEN** 10 заявлений, первое 2026-09-01, 3 с зачислением
- **THEN** `first_app_date` = '2026-09-01', `app_cnt` = 10, `app_with_zachisl_cnt` = 3, `app_no_zachisl_cnt` = 7

### Requirement: Без договора и зачислений
'Заявление из ВСП без договора и зачислений' SHALL срабатывать, если признак договора = 0 и `app_no_zachisl_cnt > 0`.

#### Scenario: Часть без зачислений
- **WHEN** договора нет, 10 заявлений, 3 с зачислением
- **THEN** строка с `app_no_zachisl_cnt` = 7

#### Scenario: Все с зачислениями
- **WHEN** договора нет, все заявления с зачислением
- **THEN** строки нет

### Requirement: С договором
'Заявление из ВСП с договором,(но по договору в сумме нет зачислений. По договору смотреть за последний полный месяц + до сегодняшней даты)' SHALL срабатывать, если признак договора = 1 и `app_no_zachisl_cnt > 0`.

#### Scenario: Часть без зачислений
- **WHEN** договор есть, 10 заявлений, 3 с зачислением
- **THEN** строка с `app_cnt` = 10, `app_no_zachisl_cnt` = 7

#### Scenario: Все с зачислениями
- **WHEN** договор есть, все заявления с зачислением
- **THEN** строки нет
