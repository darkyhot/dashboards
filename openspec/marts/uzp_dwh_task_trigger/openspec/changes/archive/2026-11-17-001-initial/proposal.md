# Proposal

## Why

Задачи сотрудникам строятся по триггерам клиента. Витрины триггеров нет. Новая витрина
`uzp_dwh_task_trigger` хранит сработавшие триггеры по паре ИНН + ГОСБ с параметрами в JSON.

## What Changes

- Витрина `uzp_dwh_task_trigger`: одна строка — один триггер по паре за период. Поля — по интенту.
- Ежемесячная функция: период — месяц, `end_dt` — параметр. 15 триггеров:
  - ЕПП флаг, Ср чек ниже среднего, Отрицательный потенциал, Кп первое зачисление;
  - Сезонный тип деятельности, Высокая текучка, Есть договор нет зачисления;
  - Контактная политика 4 месяца, Доля по клиенту больше 90%;
  - 4 триггера по заявлениям ВСП / МП СБОЛ: бумажные и электронные, за месяц и за 3 месяца;
  - 2 триггера оттока.
- Еженедельная функция: период Пн–Вс, `end_dt` — параметр. 2 триггера по заявлениям ВСП.

Вне рамок — триггеры с пометкой «ограничение» в интенте.

## Capabilities

### New Capabilities
- `trigger-mart`: поля, ключ, периоды, перерасчёт, обязательные проверки ККД (статус 98).
- `monthly-triggers`: правила и JSON 15 ежемесячных триггеров.
- `weekly-triggers`: правила и JSON 2 еженедельных триггеров.
