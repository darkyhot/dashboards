# weekly-triggers Specification

## Purpose

Функция `uzp_dwh_task_trigger_week_calc` рассчитывает 2 триггера по заявлениям ВСП / МП СБОЛ за
неделю даты `p_end_dttm`. `start_dt` — понедельник, `end_dt` — воскресенье.
Результат сохраняется в [витрине триггеров](../trigger-mart/spec.md).

**Список триггеров**

1. [Заявление из ВСП без договора и зачислений](#requirement-заявление-из-всп-без-договора-и-зачислений)
2. [Заявление из ВСП с договором без зачислений](#requirement-заявление-из-всп-с-договором-без-зачислений)

## Requirements

### Requirement: Заявления недели
Триггеры SHALL строиться по бумажным и электронным заявлениям вместе с `report_dt` в `start_dt`…`end_dt`. Отбор — по правилу [«Заявление ВСП»](../monthly-triggers/spec.md#requirement-заявление-всп).

#### Scenario: Вне недели
- **WHEN** неделя 2026-11-09…2026-11-15, заявление 2026-11-08
- **THEN** заявление не входит в неделю

### Requirement: Признак договора
Признак договора пары SHALL быть 1, если у ИНН есть [действующий договор](../monthly-triggers/spec.md#requirement-действующий-договор), иначе 0. ГОСБ договора не учитывается.

#### Scenario: Договор действует
- **WHEN** у ИНН `end_dt` > `current_date`
- **THEN** признак договора = 1

### Requirement: Признак зачисления
Признак зачисления заявления SHALL быть 1, если есть [зачисление по заявлению](../monthly-triggers/spec.md#requirement-зачисление-по-заявлению), иначе 0.

#### Scenario: Зачисление до заявления
- **WHEN** зачисление было за день до заявления, после — нет
- **THEN** признак зачисления = 0

### Requirement: JSON недельных триггеров
Оба триггера SHALL передавать в JSON четыре ключа. `first_app_date` — дата первого заявления за неделю в формате `ГГГГ-ММ-ДД`. `app_cnt` — число заявлений, `app_with_zachisl_cnt` — число заявлений с зачислением. `app_no_zachisl_cnt` — число заявлений без зачисления (`app_cnt − app_with_zachisl_cnt`).

#### Scenario: 3 из 10
- **WHEN** 10 заявлений, первое 2026-09-01, 3 с зачислением
- **THEN** `first_app_date` = '2026-09-01', `app_cnt` = 10, `app_with_zachisl_cnt` = 3, `app_no_zachisl_cnt` = 7

### Requirement: Заявление из ВСП без договора и зачислений
Тип — «Основной». Триггер SHALL срабатывать за расчётную неделю, если признак договора = 0 и `app_no_zachisl_cnt > 0`. Результат — [общий JSON недельных триггеров](#requirement-json-недельных-триггеров).

#### Scenario: Часть без зачислений
- **WHEN** договора нет, 10 заявлений, 3 с зачислением
- **THEN** строка с `app_no_zachisl_cnt` = 7

#### Scenario: Все с зачислениями
- **WHEN** договора нет, все заявления с зачислением
- **THEN** строки нет

### Requirement: Заявление из ВСП с договором без зачислений
Тип — «Основной». Триггер SHALL срабатывать за расчётную неделю, если признак договора = 1 и `app_no_zachisl_cnt > 0`. Результат — [общий JSON недельных триггеров](#requirement-json-недельных-триггеров).

#### Scenario: Часть без зачислений
- **WHEN** договор есть, 10 заявлений, 3 с зачислением
- **THEN** строка с `app_cnt` = 10, `app_no_zachisl_cnt` = 7

#### Scenario: Все с зачислениями
- **WHEN** договор есть, все заявления с зачислением
- **THEN** строки нет
